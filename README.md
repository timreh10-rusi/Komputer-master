# Компьютерный мастер — сайт

Одностраничный сайт мастера по ремонту и настройке компьютерной техники (Новороссийск, выезд и удалённо).

Идея: сайт ведёт себя как компьютер, который чинят при вас. При загрузке «система» сообщает об ошибке, Сергей запускает `repair --all`,
а пока вы листаете, индикатор «здоровье системы» растёт до 100 %. Камера «влетает» в экран ноутбука, и внутри оказываются услуги, видео, отзывы и контакты.

## Как выложить на Cloudflare Pages

Корень репозитория уже готов к публикации: `index.html`, `assets/`, `sergey.mp4`, `poster.webp` и остальные файлы лежат рядом, как раньше.

1. В Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**, выберите репозиторий `Komputer-master`.
2. **Framework preset:** None. **Build command:** оставьте пустым. **Build output directory:** `/` (или `.`).
3. Нажмите **Save and Deploy**. Каждый коммит в `main` будет выкладываться сам.

Домен: когда сайт переедет на `komputernyi-master.ru`, пересоберите его с этим адресом (см. «Как пересобрать»): он попадёт в `canonical`, превью для соцсетей, `robots.txt` и `sitemap.xml`.

## Как поменять текст, телефон, ссылки

Все тексты лежат прямо в HTML, это обычные слова, а не код.

- Быстро, без установки программ: откройте `index.html` в корне репозитория на GitHub (значок карандаша), найдите нужное слово (Ctrl+F) и поправьте.
- Номер телефона и ссылка WhatsApp встречаются в нескольких местах: ищите `79024089022` и `+7 902 408-90-22`.
- Если потом будете пересобирать сайт, повторите те же правки в `app/index.html`, иначе сборка перезапишет корневой файл.

## Как пересобрать (для разработчика)

Нужен Node.js 20 или новее.

```bash
cd app
npm install
npm run dev        # разработка: http://127.0.0.1:5173
npm run build      # проверка типов + сборка прямо в корень репозитория
SITE_URL=https://komputernyi-master.ru npm run build   # с адресом сайта
```

Сборка кладёт результат в корень репозитория (`index.html`, `assets/`, `favicon.svg`, `robots.txt`, `sitemap.xml`, …). Видео `sergey.mp4` и постер `poster.webp` в сборку не копируются: они лежат в корне и остаются на месте.

## Структура

```
app/                    исходники (Vite + TypeScript)
  index.html            весь контент сайта
  src/styles/           дизайн-токены и CSS
  src/core/             цикл кадров, плавный скролл, регулятор качества, проверка видеокарты
  src/gl/               WebGL-сцена: дождь, ноутбук, заголовок, глобус (Three.js)
  src/sections/         главы: главный экран, услуги, видео, о мастере, отзывы, контакты
  src/ui/               шапка, меню, курсор, загрузчик, появления
  src/fonts/            шрифты (кириллица и латиница)
  public/               картинки и иконки, которые попадают в корень при сборке
  scripts/              проверки и генераторы (см. ниже)
index.html, assets/, …  готовая сборка (её и публикуем)
sergey.mp4, poster.webp видео и обложка
```

## Скорость и плавность

- Один холст WebGL и один цикл кадров на всю страницу. На кадр уходит около 1 мс работы JavaScript.
- **Регулятор качества** следит за временем кадра и сам снижает разрешение и эффекты на слабых устройствах (уровни 3 → 2 → 1 → 0).
- Если браузер сообщает о программной отрисовке (нет видеокарты), включается **лёгкая версия**: те же тексты и вёрстка, ноутбук как картинка, без загрузки 3D.
- Видео (9 МБ) не грузится, пока не нажата кнопка «Смотреть».
- Проверить на телефоне: откройте сайт с `?perf` в конце адреса. Покажется FPS, время кадра, уровень качества и число ресурсов GL.
- Режим «меньше движения» в системе отключает «влёт в экран», плавный скролл и автолистание услуг.

Служебные параметры адреса: `?perf` (панель), `?tier=1|2|3` (принудительный уровень), `?nointro` (без загрузчика), `?nogl` (лёгкая версия).

## Проверки и генераторы (`app/scripts`)

| Файл | Что делает |
| --- | --- |
| `shots.mjs` | скриншоты на разных экранах (Playwright) |
| `interact.mjs` | живой сценарий: загрузчик, вступление, ноутбук, услуги, часы |
| `perf.mjs` | замер кадров, долгих задач, памяти и ресурсов GL при многократной прокрутке |
| `a11y.mjs` | автопроверка доступности (axe-core) |
| `make-assets.mjs` | рисует из сцены `laptop.webp`, `og.jpg` и иконки |
| `make-landmask.mjs` | строит маску суши для глобуса из Natural Earth |
