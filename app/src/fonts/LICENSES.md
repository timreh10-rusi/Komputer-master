# Шрифты

Шрифты лежат в репозитории (без запросов к внешним серверам). Все — под SIL Open Font License 1.1,
свободно для коммерческого использования:

- **Onest** — основной текст. © The Onest Project Authors.
- **Oswald** — крупные заголовки. © The Oswald Project Authors.
- **JetBrains Mono** — подписи, индикатор, терминал. © The JetBrains Mono Project Authors.
- **Caveat** — рукописная заметка у видео (оставлены только нужные буквы). © The Caveat Project Authors.

Файлы получены из пакетов Fontsource и урезаны до кириллицы и латиницы (знак ₽ — отдельным мини-файлом).
